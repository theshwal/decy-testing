# DECY Alpha 2 — Tester guide

Guide court pour tester l’APK Alpha 2 de DECY.  
Short guide for testing the DECY Alpha 2 APK.  
Guía breve para probar el APK Alpha 2 de DECY.

---

## Français

### Objectif du test

Ce test sert à vérifier si DECY est compréhensible et utile pour prendre de meilleures décisions concrètes : biens du foyer, contrats, abonnements, réparations, remplacements et rappels.

Durée recommandée : **15 à 20 minutes**.

### Avant de commencer

- Installez l’APK fourni dans la section **Releases**.
- Si une clé alpha est demandée, utilisez uniquement la clé transmise directement par l’équipe DECY.
- Ne publiez jamais votre clé alpha dans une issue publique.
- N’ajoutez pas de vraies données sensibles : contrat complet, facture, adresse, numéro client, coordonnées bancaires.

### Parcours conseillé

1. **Lancer l’app**
   - Lire l’onboarding.
   - Dire si la promesse est claire ou non.

2. **Ajouter un bien**
   - Exemple : lave-linge, voiture, chaudière, ordinateur, frigo.
   - Vérifier si les champs et la trajectoire sont compréhensibles.
   - Observer si DECY explique clairement ce qui peut attendre ou ce qui mérite attention.

3. **Ajouter un engagement**
   - Exemple : assurance habitation, abonnement, contrat énergie, forfait mobile.
   - Tester un choix : garder, comparer, renégocier, arrêter ou revoir plus tard.
   - Vérifier si la prochaine action est claire.

4. **Regarder la Home**
   - Est-ce que la priorité affichée est compréhensible ?
   - Est-ce que la recommandation semble logique ?
   - Est-ce que l’action proposée est claire ?

5. **Tester les rappels / le temps si disponible**
   - Certains builds alpha peuvent afficher des outils de test temporel.
   - Si vous voyez un badge de date simulée, c’est un outil alpha pour tester les décisions dans le temps.

6. **Faire un retour**
   - Utilisez les formulaires d’issues du dépôt.
   - Le meilleur retour explique : ce que vous vouliez faire, ce qui s’est passé, ce qui était clair ou confus.

### Questions utiles pour le retour

- Ai-je compris à quoi sert DECY en moins de 2 minutes ?
- Ai-je su quoi ajouter en premier ?
- La recommandation était-elle claire ?
- Ai-je compris ce qui peut attendre ?
- Les mots utilisés sont-ils naturels ?
- Y a-t-il une action que je n’ai pas comprise ?
- Est-ce que je réutiliserais l’app plus tard ?

## English

### Test objective

This test checks whether DECY is understandable and useful for practical decisions: household items, contracts, subscriptions, repairs, replacements, and reminders.

Recommended duration: **15 to 20 minutes**.

### Before starting

- Install the APK provided in the **Releases** section.
- If an alpha key is required, use only the key sent directly by the DECY team.
- Never post your alpha key in a public issue.
- Do not enter or publish sensitive real data: full contracts, invoices, addresses, customer numbers, banking details.

### Suggested test flow

1. **Launch the app**
   - Read the onboarding.
   - Say whether the promise is clear or not.

2. **Add a household item**
   - Example: washing machine, car, boiler, computer, fridge.
   - Check whether the fields and trajectory are understandable.
   - Observe whether DECY clearly explains what can wait and what needs attention.

3. **Add a contract or subscription**
   - Example: home insurance, subscription, energy contract, mobile plan.
   - Try a choice: keep, compare, renegotiate, stop, or review later.
   - Check whether the next action is clear.

4. **Look at the Home screen**
   - Is the displayed priority understandable?
   - Does the recommendation feel logical?
   - Is the proposed action clear?

5. **Test reminders / time if available**
   - Some alpha builds may show time-testing tools.
   - If you see a simulated date badge, it is an alpha tool for testing time-based decisions.

6. **Submit feedback**
   - Use the repository issue forms.
   - The best feedback explains what you tried to do, what happened, and what was clear or confusing.

### Useful feedback questions

- Did I understand what DECY is for in less than 2 minutes?
- Did I know what to add first?
- Was the recommendation clear?
- Did I understand what can wait?
- Did the wording feel natural?
- Was there any action I did not understand?
- Would I use the app again later?

## Español

### Objetivo de la prueba

Esta prueba sirve para comprobar si DECY es comprensible y útil para decisiones prácticas: objetos del hogar, contratos, suscripciones, reparaciones, reemplazos y recordatorios.

Duración recomendada: **15 a 20 minutos**.

### Antes de empezar

- Instala el APK disponible en la sección **Releases**.
- Si se requiere una clave alfa, usa solo la clave enviada directamente por el equipo DECY.
- No publiques nunca tu clave alfa en una issue pública.
- No introduzcas ni publiques datos reales sensibles: contratos completos, facturas, direcciones, números de cliente o datos bancarios.

### Recorrido recomendado

1. **Abrir la app**
   - Leer el onboarding.
   - Decir si la promesa se entiende o no.

2. **Añadir un objeto del hogar**
   - Ejemplo: lavadora, coche, caldera, ordenador, frigorífico.
   - Comprobar si los campos y la trayectoria se entienden.
   - Observar si DECY explica claramente qué puede esperar y qué merece atención.

3. **Añadir un contrato o suscripción**
   - Ejemplo: seguro del hogar, suscripción, contrato de energía, tarifa móvil.
   - Probar una elección: conservar, comparar, renegociar, cancelar o revisar más tarde.
   - Comprobar si la próxima acción está clara.

4. **Mirar la pantalla principal**
   - ¿Se entiende la prioridad mostrada?
   - ¿La recomendación parece lógica?
   - ¿La acción propuesta está clara?

5. **Probar recordatorios / tiempo si está disponible**
   - Algunas versiones alfa pueden mostrar herramientas de prueba temporal.
   - Si ves una insignia de fecha simulada, es una herramienta alfa para probar decisiones en el tiempo.

6. **Enviar comentarios**
   - Usa los formularios de issues del repositorio.
   - El mejor comentario explica qué intentabas hacer, qué ocurrió y qué fue claro o confuso.

### Preguntas útiles para el feedback

- ¿Entendí para qué sirve DECY en menos de 2 minutos?
- ¿Supe qué añadir primero?
- ¿La recomendación fue clara?
- ¿Entendí qué puede esperar?
- ¿Las palabras usadas suenan naturales?
- ¿Hubo alguna acción que no entendí?
- ¿Volvería a usar la app más adelante?
