## Français

### DECY Alpha 2 — APK de test

Cette version est une **alpha de test**. Elle sert à vérifier si DECY est compréhensible, utile et suffisamment clair dans des situations concrètes.

À tester en priorité :

- comprendre l’onboarding ;
- ajouter un bien ou équipement ;
- ajouter un contrat, une assurance ou un abonnement ;
- comprendre pourquoi DECY recommande une action ;
- choisir entre garder, comparer, réparer, remplacer, arrêter ou revoir plus tard ;
- tester les rappels et l’avancement dans le temps ;
- signaler les écrans ou textes confus.

### Accès alpha

L’accès peut nécessiter une clé alpha. Ne publiez jamais de clé alpha dans une issue publique.

### Retours

Merci d’utiliser les formulaires d’issues du dépôt :

- Bug report ;
- Alpha feedback ;
- Confusing screen / wording ;
- Feature idea ;
- Alpha access request ;
- Language / translation issue.

### Confidentialité

Ne publiez pas de données personnelles, contrats, factures, adresses, numéros client, clés alpha, tokens ou documents sensibles.
